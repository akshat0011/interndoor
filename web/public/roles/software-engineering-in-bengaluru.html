What the work is

Software engineers design, write, test and maintain the code behind a company’s products and internal systems. Entry-level roles in India go by many titles — Software Engineer, SDE-1, Associate Software Engineer, Software Developer — and most ask for data structures, one programming language used well, and the basics of how software is built and shipped.
