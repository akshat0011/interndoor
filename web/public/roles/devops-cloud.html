What the work is

DevOps, cloud and site reliability engineers keep software running: they build the pipelines that test and deploy it, manage the cloud infrastructure it runs on and respond when it breaks. The usual asks are Linux, a cloud platform (AWS, Azure or GCP), containers and Kubernetes, and scripting.
