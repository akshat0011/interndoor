Software Engineering Intern

Backend & data engineering

RemoteIndia InternshipPart timeUnpaid Posted 6 Sept 2026

The gist

InternDoor is a job board for engineering internships. You would work on the thing itself — the Node.js collector that reads job boards, the classifier that decides what belongs on it, and the generator that publishes about two thousand pages a day.

What you would actually do

  • Write and review Node.js that collects, classifies and publishes engineering internships
  • Work on the static site generator, its structured data and its test suite
  • Own one piece of the pipeline end to end, from the raw data to the page a student reads

What we look for

  • Comfortable in Java or C++, and solid on data structures and algorithms
  • Can read code you did not write and change it without breaking it
  • Studying in India, and able to work remotely
JavaC++Data structuresAlgorithmsSQLGitREST APIsLinux

Pay

This internship is unpaid. There is no stipend and no other compensation. It is remote and part time. We would rather say that on the posting than in a reply three weeks later.
