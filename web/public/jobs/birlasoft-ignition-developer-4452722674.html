The gist

As an Ignition Developer, you'll design and deploy industrial applications using Ignition and Sepasoft. You'll work on SCADA/HMI systems, integrate with industrial protocols, and develop backend logic. This role suits those with technical skills in automation and software development.

What you would actually do

  • Develop SCADA/HMI apps with Ignition and Sepasoft modules
  • Integrate with PLCs and protocols like Modbus, OPC UA
  • Write Python scripts and SQL for backend logic
  • Deploy Ignition gateways and support system testing
