The gist

This role involves designing and maintaining a monitoring system for SSAS cubes, focusing on performance, resource usage, and operational health. The candidate will work with SQL Server tools to collect, analyze, and report on data, supporting troubleshooting and capacity planning. It suits someone with strong SQL Server expertise and an interest in data infrastructure.

What you would actually do

  • Build SSAS monitoring framework for cube availability, performance, and resource usage
  • Use SQL Server DMVs, Extended Events, and T-SQL for data collection and analysis
  • Develop Power BI-ready datasets and historical trend reports for operational insights
